## SAPI4SDK.exe
The Windows Speech API 4 SDK released by Microsoft in 1999.


## spchapi.exe
The text-to-speech runtime released by Microsoft in 1999, need to install this runtime to utilize the voices.

## At&T Flextalk 2.1
_submitted by @h4rm0n1c I've not personally tested these._


@h4rm0n1c writes in [#1](https://github.com/LouisGameDev/Microsoft-Sam-Mary-Mike-TruVoice-WSAPI4/issues/1) :

https://archive.org/details/flextalk

this one is fantastic. a genuine piece of lost technology has been rediscovered recently, a SAPI 4.0 voice by AT&T from the 90s.

this was used to make the VOX/Announcer/Black Mesa Announcement System wav files in the first HalfLife game from Valve Software.

I am currently working on software to revive VOX/BMAS and make it a live use option for any purpose with the correct prosody as used in the game.

This would also allow modders to make original voice lines in the characteristic style, it's also just a really good prosody for more legible robotic/staccato sounding TTS announcements that could be used elsewhere.

Thought you might appreciate adding this one to your collection because it's downright iconic/a major part of that era.

This was put out there free by AT&T for the general public's use at the time as I understand it, the watson stuff this thing installs I don't know anything about, but flextalk is there.

I've even gotten this working under wine, so it's pretty awesome. the control panel it ships with is very neat.

The two voices are called "Keith Bell" and "Kerry Watson"
